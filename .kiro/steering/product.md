# Product

Jev Agent Guardrail is an HTTP endpoint that decides whether an AI agent's proposed tool call should run. It asks Jev (TypeSafe's System One decision model, via OpenRouter) three typed questions about the call and returns one of three verdicts: `allow`, `ask`, `block`.

Who it is for: developers running LLM agents that have real tools (shell, HTTP, file system, cloud APIs) and who need a fast, non-injectable check between "the model wants to do X" and "X happens".

Non-goals:
- It does not replace IAM, sandboxing, or a denylist. It is one more layer.
- It does not explain its decisions in prose. Jev returns probabilities only. The `reasons` field is generated by our policy code, not by the model.
- It does not run the tool. The caller does, based on the verdict.

Product rules:
- Fail closed. If Jev is unreachable the verdict is `ask`, never `allow`.
- Every decision is logged. Auditability is a feature, not a debug aid.
- Thresholds are configuration, not code. Users tune them on their own labelled data.
