# Writing rules for docs and blog drafts in this repo

- First person "I" (solo build). No em dashes anywhere, use commas or short sentences.
- Grounded, not flexy. Show the code and the numbers, skip the adjectives.
- Every claim about Jev or AWS pricing links to the source page.
- Never name ShellKode clients. Sector names only.
- Code blocks must be copy-pasteable and match the actual files in `src/`.
